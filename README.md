# Customers-Segmentation-Dashboard
📊 Mall Customers Segmentation Analysis Dashboard:
This project focuses on analyzing customer behavior and spending patterns using data analytics and visualization techniques. The dashboard was developed in Power BI to help businesses understand different customer segments and identify high-value customers for targeted marketing strategies.

🔧 Tools & Technologies
      Power BI
      Microsoft Excel
      Data Cleaning & Transformation
      Data Visualization

📈 Key Dashboard Features:
      Interactive customer segmentation analysis based on annual income and spending score
      KPI cards showing average age, total customers, and total annual income  
      Gender-based analysis of customer spending behavior
      Dynamic filters and slicers for gender and customer ID
      Visual insights on spending score vs annual income distribution

💡 Key Insights:
      Identified different customer groups based on income and spending behavior
      High-income customers do not always have the highest spending score
      Gender-wise analysis helps understand purchasing patterns

🎯 Project Objective
      The goal of this project is to demonstrate data analysis, dashboard development, and business insight generation using Power BI.
